# 🔥 حرائق الجزائر — Wildfires Help

تطبيق ويب خفيف (PWA) لتتبع حرائق الغابات في الجزائر: خريطة تفاعلية، إبلاغ عن حريق،
وأرقام الطوارئ الوطنية. عربي بالكامل مع دعم RTL، مصمّم للهاتف أولاً.

> **بيانات حقيقية تُحدَّث تلقائياً:** التطبيق يجلب نقاط الحريق من **NASA FIRMS**
> عبر دالة خادم مرفقة (`api/fires.ts`). يكفي ضبط `FIRMS_MAP_KEY` (مفتاح مجاني).
>
> ⚠️ بدون المفتاح — أو عند تعذّر الوصول للمصدر — يعود التطبيق إلى
> **بيانات تجريبية موسومة بوضوح** مع رسالة تشرح السبب. لا يُعرض التجريبي
> على أنه حقيقي في أي حال.
>
> ⚠️ نقاط FIRMS هي **رصد فضائي آلي غير مؤكد ميدانياً** — تُعرض بحدود متقطّعة
> وشارة صريحة، ولا تُحسب أبداً ضمن «المؤكد».

## متغيرات البيئة

انسخ `.env.example` إلى `.env.local` محلياً، أو اضبطها في
Vercel → Settings → Environment Variables.

### متغيرات الخادم (سرّية — لا تصل إلى المتصفح)

| المتغير | الوصف | الافتراضي |
|---|---|---|
| `FIRMS_MAP_KEY` | **الوحيد المطلوب للبيانات الحقيقية.** مفتاح مجاني من [FIRMS](https://firms.modaps.eosdis.nasa.gov/api/map_key/) | — |
| `FIRMS_SOURCES` | مصادر الأقمار مفصولة بفواصل | `VIIRS_SNPP_NRT,VIIRS_NOAA20_NRT` |
| `FIRMS_DAYS` | عدد الأيام السابقة (1..10) | `1` |

### متغيرات الواجهة (اختيارية كلها)

| المتغير | الوصف | الافتراضي |
|---|---|---|
| `VITE_FIRES_API_URL` | مصدر الحرائق. `off` يُجبر البيانات التجريبية | `/api/fires` |
| `VITE_FIRES_API_AUTH` | ترويسة `Authorization` للمصدر أعلاه | — |
| `VITE_REPORT_ENDPOINT` | عنوان يستقبل البلاغات عبر `POST JSON` | — |
| `VITE_REPORT_ENDPOINT_AUTH` | ترويسة `Authorization` لنقطة البلاغات | — |
| `VITE_MAP_TILE_URL` | قالب بلاط الخريطة | OpenStreetMap |
| `VITE_MAP_TILE_ATTRIBUTION` | نص إسناد البلاط | OpenStreetMap |
| `VITE_REFRESH_MINUTES` | إعادة الجلب في المتصفح بالدقائق (`0` = تعطيل) | `10` |
| `VITE_RECENT_HOURS` | نافذة مرشّح «حديث» بالساعات | `24` |

> متغيرات `VITE_*` تُحزَم داخل ملفات JavaScript العلنية.
> **لا تضع فيها أي مفتاح سرّي** — ولهذا يبقى `FIRMS_MAP_KEY` على الخادم وحده.

## البيانات الحقيقية: كيف تعمل؟

```
NASA FIRMS  ──►  api/fires.ts  ──►  حافة Vercel  ──►  المتصفح
   (CSV)          دالة الخادم       تخزين مؤقت      كل 10 دقائق
                                    s-maxage=600
```

الدالة `api/fires.ts` تنادي واجهة FIRMS القُطرية للجزائر (`DZA`) وتقوم بـ:

1. **إخفاء المفتاح** — FIRMS يتطلب `MAP_KEY` ولا يجوز وضعه في المتصفح.
2. **تجاوز CORS** — FIRMS لا يرسل ترويسات CORS أصلاً.
3. **دمج النقاط المتجاورة** — الحريق الواحد يظهر كعشرات البكسلات
   (بكسل VIIRS ≈ 375 م). بدون الدمج يصبح العدّاد مضلّلاً («347 حريقاً»
   بدل «12»). الدمج بالمسافة الحقيقية ضمن 2 كم، لا بشبكة ثابتة —
   الشبكة الثابتة تفصل نقطتين متجاورتين لمجرد مرور حدّ خلية بينهما.
4. **تقدير الشدة من FRP** (Fire Radiative Power): `≥50 MW` حرج،
   `≥15` خطير، وما دونه متوسط.
5. **توحيد الثقة** — VIIRS يعطي حروفاً (`l`/`n`/`h`) وMODIS نسبة 0–100.
6. **تقدير الولاية** من الإحداثيات (أقرب مركز ولاية).

منطق التحويل مغطّى باختبارات: `npm run test:firms`.

### التحديث التلقائي

| الطبقة | الآلية | الدورية |
|---|---|---|
| حافة Vercel | `s-maxage=600, stale-while-revalidate=1800` | كل 10 دقائق |
| المتصفح | `VITE_REFRESH_MINUTES` | كل 10 دقائق |
| PWA | تحديث صامت لعامل الخدمة | عند كل زيارة |

لا حاجة لأي مهمة مجدولة أو قاعدة بيانات.

### حدود يجب معرفتها

- نقاط FIRMS **رصد آلي غير مؤكد**: قد تكون مصنعاً أو حرق مخلفات زراعية،
  وقد تغيب حرائق حقيقية تحت الغيوم. لذلك `verified: false` دائماً،
  وتُعرض بحدود متقطّعة وشارة «🛰️ رصد فضائي — غير مؤكد»،
  ولا يشملها مرشّح «مؤكد».
- الرصد **لحظي**: نقطة رُصدت قبل ساعات لا تعني أن الحريق ما زال مشتعلاً.
- **البلدية غير متوفرة** من FIRMS، والولاية مُقدَّرة من الإحداثيات.
- حصّة FIRMS: 5000 طلب لكل 10 دقائق — التخزين المؤقت يجعل الاستهلاك
  ثابتاً مهما بلغ عدد الزوار.

### عند فشل المصدر

لا يُترك التطبيق فارغاً: يعود إلى البيانات التجريبية مع رسالة صريحة
تشرح السبب، ويبقى وسم «بيانات تجريبية» ظاهراً. التجريبي لا يُعرض
على أنه حقيقي في أي حال.

### مصدر بديل

لربط مصدر آخر (بيانات رسمية مثلاً) اضبط `VITE_FIRES_API_URL` على عنوانه.
المحوّل في `src/lib/api.ts` يقبل مصفوفة أو `{ fires: [...] }` أو GeoJSON،
ومرن مع أسماء الحقول:

| الحقل | المرادفات المقبولة |
|---|---|
| الإحداثيات | `lat`/`latitude`/`y` · `lon`/`lng`/`longitude`/`x` · أو `geometry.coordinates` |
| الوقت | `reportedAt`/`date`/`timestamp` · أو `acq_date` + `acq_time` |
| الشدة | `severity`/`level` — وإن غابت تُستنتج من `confidence` |
| الحالة | `status`/`state` (`active` / `contained` / `extinguished`) |
| نوع المصدر | `sourceKind`/`instrument`/`satellite` |
| التأكيد | `verified`/`confirmed` — وإن غاب فالمصادر الرسمية فقط تُعتبر مؤكدة |

**مهم:** أبقِ `verified: false` لأي رصد فضائي — التمييز بين المؤكد
وغير المؤكد هو أهم ضمانة في هذا التطبيق.

## استقبال البلاغات

اضبط `VITE_REPORT_ENDPOINT` على أي عنوان يقبل `POST application/json`.
جسم الطلب:

```jsonc
{
  "lat": 36.75123,
  "lon": 5.08211,
  "wilayaCode": "06",
  "wilaya": "بجاية",
  "commune": "أميزور",
  "severity": "serious",          // moderate | serious | critical
  "description": "دخان كثيف…",
  "photo": "data:image/jpeg;base64,…", // اختياري، مضغوطة إلى 1280px
  "reportedAt": "2026-08-29T05:12:00Z",
  "userAgent": "…"
}
```

الاستجابة `2xx` تعني نجاح الاستلام. أي خطأ شبكة أو `5xx` يجعل التطبيق يحفظ البلاغ
في `localStorage` ويعيد إرساله تلقائياً عند عودة الاتصال.

خيارات جاهزة: دالة Vercel، Cloudflare Worker، Formspree، Google Apps Script، n8n…

```ts
// api/report.ts — مثال بسيط يعيد التوجيه إلى Webhook
export default async function handler(request: Request) {
  if (request.method !== 'POST') return new Response('Method Not Allowed', { status: 405 })
  const report = await request.json()
  await fetch(process.env.REPORT_WEBHOOK_URL!, {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify(report),
  })
  return new Response(null, { status: 204 })
}
```

ثم: `VITE_REPORT_ENDPOINT=/api/report`

## النشر على Vercel

1. اربط المستودع بمشروع Vercel — الإطار يُكتشف تلقائياً (Vite)،
   و`vercel.json` موجود مسبقاً، ودالة `api/fires.ts` تُنشر تلقائياً.
2. اطلب مفتاح FIRMS المجاني من
   <https://firms.modaps.eosdis.nasa.gov/api/map_key/>
3. أضفه في Settings → Environment Variables باسم `FIRMS_MAP_KEY`.
4. أعد النشر. من هذه اللحظة تُعرض حرائق حقيقية وتتحدّث تلقائياً.

بدون الخطوتين 2–3 يعمل الموقع ويعرض بيانات تجريبية موسومة.
لا حاجة لأي قاعدة بيانات.
